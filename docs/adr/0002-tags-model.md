# ADR 0002: Модель фильтрации на основе групп тегов

- **Статус:** Принято (2026-11-09)

## Контекст
Фильтры квиза («С кем вы?», «Какой вайб?», сезонные подборки и т.д.) со временем будут расширяться. Жёсткое хранение каждой категории в отдельных колонках таблицы `places` потребует миграций БД и правок кода при каждом новом вопросе квиза.

## Решение
Использовать таблицы `tag_groups` (шаг/категория квиза) и `tags` (вариант ответа), связанные с `places` и `scenarios` через таблицы многие-ко-многим (`place_tags`, `scenario_tags`).

Алгоритм ранжирования вынесен в чистый модуль `app/modules/recommendations/scoring.py`:
- `audience` («С кем вы?») — обязательное совпадение (если выбрано пользователем) и вес `3`.
- `vibe` («Какой вайб?») — вес `2`.
- Прочие группы тегов — вес `1`.

## Последствия
- Новые категории и теги добавляются через `/admin` без миграций БД и без изменений фронтенда (шаги квиза рендерятся динамически из `GET /api/v1/tags`).
- Логика скоринга покрыта быстрыми юнит-тестами без участия базы данных.
