# ADR 0001: Выбор технологического стека

- **Статус:** Принято (2026-11-09)

## Контекст
Нужно создать веб-приложение для подбора досуга в Беларуси (начиная с Гродно) с быстрым стартом в одного разработчика, строгим контролем качества кода и возможностью в будущем подключить мобильный клиент или Telegram WebApp.

## Решение
- **Backend:** Python 3.12 + FastAPI + SQLAlchemy 2.0 (async) + Alembic + Pydantic v2 + `sqladmin`.
- **База данных:** локально SQLite (`aiosqlite`), на продакшене — переход на PostgreSQL (`asyncpg`) сменой `DATABASE_URL`.
- **Frontend:** React 19 + TypeScript (strict) + Vite + Tailwind CSS v4 + TanStack Query + Zustand.
- **Контракт API:** автогенерация TypeScript-типов из OpenAPI-схемы FastAPI (`openapi-typescript` + `openapi-fetch`).

## Последствия
- Единый контракт между фронтом и бэком без ручного дублирования DTO.
- Готовая веб-админка `/admin` из коробки (`sqladmin`) для наполнения базы мест без разработки отдельного фронтенда админки.
- Для совместимости SQLite и PostgreSQL не используем специфичные диалектные конструкции до переключения на Postgres.
